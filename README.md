# NSI Nomenclature Service

Централизованный микросервис управления нормативно-справочной информацией. Проект решает проблему децентрализованного создания и расхождения данных по крепежным изделиям (пилотной группы "Болты") в гетерогенном IT-ландшафте промышленного предприятия.

## 1. Бизнес-проблема и цели

*   **Проблема:** Независимый ручной ввод номенклатуры в 1C:ERP, CAD, WMS-складе и B2B-портале привел к накоплению около 17000 дублирующих и некорректных записей (опечатки, смешение кириллицы/латиницы).
*   **Решение:** Разработка независимого сервиса NSI Core API как единого источника мастер-данных с превентивной валидацией по стандартам ГОСТ и асинхронным вещанием утвержденных записей подписчикам.

## 2. Зона ответственности системного аналитика на проекте

1.  **Бизнес- и системный анализ:** Формализация требований ГОСТ 1759.0-87, ГОСТ 7798-70, ГОСТ 7805-70, ГОСТ 15589-70 и проектирование детерминированного алгоритма конкатенации строк.
2.  **Архитектурное проектирование:** Разработка модели контейнеров, сквозных сценариев взаимодействия и стратегии кэширования.
3.  **Проектирование данных:** Разработка нормализованной схемы реляционной БД, структуры индексов и аналитических SQL-запросов.
4.  **Проектирование интеграций:** Разработка спецификации синхронного REST API и асинхронных контрактов шины данных.
5.  **Управление архитектурными решениями:** Фиксация технических компромиссов и ограничений бизнеса.

## 4. Ключевые инженерные решения

*   **[ADR-001](docs/adr/001-legacy-data-normalization.md):** Отказ от прямого `UPDATE` исторических данных в 1С из-за рисков нарушения закрытых финансовых периодов. Реализация нормализации «на лету» через функциональный индекс в PostgreSQL.
*   **[ADR-002](docs/adr/002-redis-cache-invalidation.md):** Снижение времени отклика Мастер-фильтра с 45 мс до < 2 мс за счет кэширования списков параметров в Redis.
*   **[ADR-003](docs/adr/003-kafka-delivery-guarantees.md):** Минимизация архитектурной сложности пилота за счет синхронного коммита с таблицей аварийного сброса `failed_events` вместо Transactional Outbox/Debezium.
